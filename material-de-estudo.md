
# Material de Estudo - Versão Inicial

- Conceito 1: Versionamento
- • É o sistema que controla e registra todas as alterações feitas em um arquivo ou projeto ao longo do tempo. Ele permite acompanhar a evolução do código e recuperar versões antigas quando necessário.
- 
- Conceito 2: Repositório
- • É a pasta ou espaço digital onde o projeto e todo o seu histórico de alterações ficam armazenados. Ele pode ser local (no seu computador) ou remoto (hospedado na nuvem, como no GitHub).
- 
- Conceito 3: Commit
• É o ato de salvar um conjunto de alterações no histórico do repositório. Cada commit funciona como uma "foto" do projeto naquele momento e exige uma mensagem explicando o que foi modificado.


- Conceito 4: Branch
É uma linha independente de desenvolvimento criada a partir do código principal. Ela serve para testar ideias ou criar novas funcionalidades sem correr o risco de estragar o projeto que já está funcionando.
- 
- Conceito 5: Merge
• É a ação de juntar as alterações feitas em uma branch separada de volta para a linha principal do projeto após testar e aprovar o código.
